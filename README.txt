JOKER TOOL — HƯỚNG DẪN SỬ DỤNG
================================

YÊU CẦU
  - Windows 10 hoặc Windows 11 (64-bit)
  - Có tài khoản Discord
  - Có Discord User Token

BƯỚC 1: CHẠY TOOL
  - Giải nén file .zip
  - Double-click "JokerTool.exe"
  - Windows có thể cảnh báo xanh:
      "Windows protected your PC"
    → Bấm "More info" → "Run anyway"

BƯỚC 2: LẤY DISCORD TOKEN

BƯỚC 3: SỬ DỤNG
  1. Mở JokerTool.exe
  2. Paste token vào ô "Discord Token"
  3. Bấm "Kiểm tra token" → nếu OK hiện tên user
  4. Bấm "Lưu" để lưu cho lần sau
  5. Chọn tab tính năng:
     - "Cày Quest": tự động cày hết quest Discord
     - "Buff Badge": buff giờ chơi + số game
     - "HypeSquad": đổi nhà HypeSquad
  6. Bấm nút bắt đầu trong tab
  7. Xem tiến độ ở khung giữa màn hình
  8. Đóng tool = dừng mọi thứ

TOKEN LƯU Ở ĐÂU?
  - %APPDATA%\JokerTool\config.json
  - Muốn xoá: mở folder trên, xoá file config.json
  - Token CỦA BẠN, không ai khác đọc được

LOG
  - %APPDATA%\JokerTool\log.txt
  - Ghi lại mọi hoạt động để tra cứu khi lỗi

LỖI THƯỜNG GẶP
  - "Token không hợp lệ": token sai/hết hạn
    → Reset lại bằng cách đăng xuất Discord web rồi đăng nhập lại
    → Hoặc đổi mật khẩu (Discord sẽ invalidate token cũ)

  - "Bị Cloudflare chặn 403": dùng VPN hoặc thử lại sau vài phút

  - "Rate limit 429": đợi 5-10 phút rồi thử lại

  - Tool bị đứng ở "Đang xác thực": kiểm tra mạng, thử tắt VPN

CẢNH BÁO QUAN TRỌNG
  Tool này vi phạm Discord ToS.
  Nên dùng TÀI KHOẢN PHỤ, KHÔNG dùng tài khoản chính.
  Tài khoản chính có thể bị ban.
  Bạn tự chịu trách nhiệm về rủi ro.
